## Governança

Registre decisões compartilhadas em Foundations. Registre decisões exclusivas em Core Web ou Core App. Mantenha exemplos de composição nas respectivas páginas Web e App do Mural. A precedência é: tokens → componente publicado → documento da plataforma → mural → especificação da tela.
